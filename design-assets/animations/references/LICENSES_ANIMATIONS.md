## 2. Permissive Usage Rules

1. **Unrestricted Modification:**  
   You may freely resize, adjust colors, modify duration, change frame rate, and re-export to other video/image formats.
2. **Multi-Format Distribution:**  
   The library distributes each asset with:
   - Raw GIF (`animations/gif/`)
   - Optimized WebP (`animations/webp/`)
   - Hardware-accelerated WebM (`animations/webm/`)
   - Lottie JSON vector format (`animations/lottie/`)
   - Static poster thumbnail (`animations/thumbnails/`)
3. **No Model Training:**  
   In compliance with project directives, these animations are strictly for UI/UX interface rendering and may not be packaged as mass training datasets for third-party AI image models.
